# Valoroyce

中文 | [English](README.en.md)

无畏契约（VALORANT）队内语音的**离线**实时字幕：听日语 / 英语，在屏幕上显示中文，像看带字幕的视频一样打外服。

```
你的电脑正在播放的声音 ──> 切句 ──> 语音识别 ──> 术语纠正 ──> 本地翻译模型 ──> 屏幕字幕
   (系统回环录音)      (Silero VAD) (Whisper 或 SenseVoice) (内置词表)     (Hy-MT2 1.8B)
```

- **完全本地**：模型下载完之后可以断网使用，不需要账号、不收费。
- **懂游戏黑话**：内置英雄 / 武器 / 地图的国服译名（`Iso`、`アイソ` → 壹决，`ヴァンダル` → 狂徒），以及常用报点和术语；识别错的近似写法会被自动纠正。词表是一个文本文件，可以自己加。
- **边说边出字幕**：对方还没说完就先显示半句，说完后定稿。
- **不碰游戏**：只是录系统声音加一个置顶的透明窗口，不读内存、不注入、不改游戏文件，和 OBS 录屏、歌词悬浮窗是同一类东西。

> 状态：早期版本。实时录音、悬浮窗和设置窗口已在一台 Windows 11 电脑（RTX 4060 笔记本显卡）上实际运行；真实对局里的识别效果还在改进，多人同时说话、背景音乐很响时仍然不可靠。遇到问题请提 issue。

## 需要什么

- Windows 10 / 11（Linux、macOS 也能跑，主要用于开发）
- 有**独立显卡**最好：语音识别用 Whisper，准确得多（约占 1.2 GB 显存），翻译模型也更快。NVIDIA、AMD、Intel 的独立显卡（显存 3 GB 以上）都可以：Whisper 用 whisper.cpp 的 Vulkan 版运行。没有独立显卡也能用：识别改用 CPU 上的 SenseVoice，准确度差不少
- 磁盘空间：N 卡配置约 6 GB，其他约 1.5 GB
- 游戏显示模式设为 **「窗口全屏」**。独占全屏下任何悬浮窗都显示不出来

## 安装

**Windows（推荐）**：到 [Releases](https://github.com/Aminorsh/valoroyce/releases) 下载 `Valoroyce-Setup-….exe`，双击安装。

- 安装程序没有数字签名，Windows 可能提示「Windows 已保护你的电脑」：点「更多信息」，再点「仍要运行」。
- 不需要管理员权限。默认装在 `%LOCALAPPDATA%\Programs\Valoroyce`，也可以选别的文件夹。
- 安装时选择要下载的模型：有独立显卡选 Whisper，没有就选 SenseVoice，再加翻译模型 Hy-MT2。（NVIDIA 专用版的 Whisper 是同一个模型的 faster-whisper 版本，一般不需要。）也可以都不选，以后在设置窗口里随时下载。
- 第一次启动先下载运行组件（约 115 MB），窗口里有进度条、速度和剩余时间。之后程序打开，开始下载你选的模型（有独立显卡约 2.3 GB，没有约 1.4 GB），自动选最快的下载源。下载完字幕自动启动，之后可以离线使用。下载可以中途取消，下次接着下。
- **更新**：下载新版安装程序直接安装。它会先关掉正在运行的 Valoroyce，模型和设置都会保留。
- **卸载**：Windows 设置 → 应用 → 「Valoroyce 实时字幕」。卸载时会问要不要同时删除模型、设置和录音。
- 出问题时，安装文件夹里的 `valoroyce.log` 记录了程序的输出，提 issue 时请附上。

从源码安装（开发用）：

1. 安装 [uv](https://docs.astral.sh/uv/)（一个 Python 管理工具）。打开 PowerShell 粘贴：

   ```powershell
   powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
   ```

2. 下载本项目（`git clone`，或在 GitHub 页面点 Code → Download ZIP 并解压）。
3. 双击 `start.bat`。第一次会自动安装依赖，然后在设置窗口里下载模型，之后直接启动。

手动方式（任何系统）：

```sh
uv sync --extra app        # 安装依赖；NVIDIA 专用版 Whisper 再加 --extra whisper（约 1.3 GB 的显卡运行库）
uv run valoroyce setup     # 下载模型和 llama.cpp；加 --whispercpp 同时下载 Whisper（任何独立显卡，Windows），--whisper 下载 NVIDIA 专用版
uv run valoroyce           # 启动（缺模型时会打开设置窗口）
```

## 使用

启动后屏幕下方出现字幕条，同时任务栏右下角的系统托盘里会多一个红色的对话气泡图标（可能收在「^ 显示隐藏的图标」里，可以把它拖出来固定在任务栏上）。点击图标打开菜单：

| 菜单项 | 作用 |
|---|---|
| 设置与模型… | 打开设置窗口（见下一节） |
| 暂停字幕 | 临时关掉字幕，再点一次恢复 |
| 调整位置 | 勾选后字幕条变成可拖动的蓝色框，拖到合适位置再取消勾选 |
| 显示原文 | 在中文上方同时显示识别出的日语 / 英语 |
| 字号 | 小 / 中 / 大 / 特大 |
| 翻译运行在 | **显卡**（更快）或 **CPU**（不占用显卡）。切换后几秒内生效 |
| 声音来源 | 选择要听哪个播放设备（见下一节） |
| 退出 | 关闭程序 |

### 设置窗口

托盘菜单里点「设置与模型…」打开。改动会立刻记住；需要重新加载模型的改动，点窗口底部的「应用更改」或关闭窗口时生效（几秒钟）。

| 页面 | 能做什么 |
|---|---|
| 模型 | 每个模型一张卡片（字幕翻译还有一张「自定义翻译模型」），写着用途、适合的硬件、大小和当前状态。**下载 / 取消 / 继续下载**、**删除**（释放磁盘空间，可随时重新下载）、取消勾选**启用**（留着文件但不使用）。语音识别模型用 ▲ ▼ 调整**使用顺序**：从上到下依次尝试，用第一个能用的。顶部可以选下载源（自动测速 / 国内镜像 / 国际源） |
| 字幕 | 字号、最多显示行数、停留时间、背景不透明度、宽度、是否显示原文、拖动调整位置 |
| 声音与识别 | 声音来源（见「只翻译队友语音」）、听哪些程序（见「和朋友另外开语音通话时」）、识别语言、是否边说边出字幕、断句停顿 |
| 翻译 | 翻译模型用显卡还是 CPU、是否翻译半句字幕；自定义翻译模型（见「字幕用自己选的翻译模型」） |
| 发消息 | 目标语言、两个快捷键（打字 / 说话）、麦克风、是否改用在线服务（地址、模型名、API key） |

设置窗口和菜单里改过的东西保存在 `valoroyce.state.json`，下次启动沿用，并且优先于 `config.toml`；删掉这个文件（或在「关于」页点「恢复默认设置」）即恢复默认。

### 给队友发文字消息

想打字和队友交流时：在托盘菜单点「发消息（中文 → 日语 / 英语）…」，或按快捷键 **Ctrl+Alt+T**，会弹出一个小输入框。输入中文按回车，译文会显示出来并**自动复制到剪贴板**，回到游戏的聊天框按 Ctrl+V 粘贴、回车发送即可。按 Esc 关闭输入框。

- 目标语言在输入框里选「日语」或「English」，会记住上次的选择。
- 英雄、武器、地图和报点会换成对方语言里的叫法，中文里的俗称和省略说法也认识（「保安」→ Cypher，「奶妈」→ Sage，「A大」→ A main，「有大」→ 有大招）。字幕里显示的始终是正式译名。
- 常见的简写会先补全再翻译：「A包」→ A 点已下包，「A大两个」→ A 大道有两个敌人，「中路一把狙」→ 中路有狙击手，「中路暮蝶」→ 暮蝶在中路。
- 程序只负责复制，不会替你往游戏里打字或发送。
- 机器翻译对简短直接的句子效果最好（「壹决残血，在B长廊」），俏皮话和网络梗容易翻歪。

**说话代替打字**：按 **Ctrl+Alt+V**（或托盘菜单「说话发消息」），对着麦克风说中文，说完停一下，会自动识别、翻译并复制，回游戏粘贴即可。想先检查识别出的文字，就在输入框里按 **Tab**（或点 🎤）说话：识别出的中文会插在光标处，确认无误再按回车翻译。

- 识别用的是 **X-ASR**，一个专门的中文模型（约 140 MB，只用 CPU，约 0.1 秒一句），在「设置与模型」的「模型」页下载。实测同样 60 句报点，它的错字比 Whisper 少一半多。没下载时用字幕的识别模型。
- 英雄、地图和报点按读音纠正，声调不同也认（「木蝶」→ 暮蝶、「杰峰」→ 捷风、「回房」→ 回防），也认识模型常写错的词（「大局」→ 大狙、「必保」→ B包）。日常的话不会被改（「大家」不会变成「大甲」）。
- 麦克风在设置窗口「发消息」页选择，默认用系统默认麦克风。
- 别用游戏里的按键说话键来说中文；如果游戏语音是「开放麦克风」，队友也会听到。

#### 想翻得更地道：给「发消息」单独换一个模型（可选）

默认情况下发消息和字幕共用同一个本地小模型，完全离线，但口语和梗翻得比较生硬。可以只给「发消息」换一个更强的模型，**字幕不受影响**（字幕也想换模型，见下一节）。两种方式任选：

**在线服务**（任何兼容 OpenAI 接口的服务都行，需要自己申请 API key）：在设置窗口的「发消息」页把模型改成「在线服务」，填上地址、模型名和 key 即可（有一个按钮可以填好 DeepSeek 的设置）。也可以写进 `config.toml`，下面以 DeepSeek 为例：

```toml
[compose]
backend = "openai"
base_url = "https://api.deepseek.com"
model = "deepseek-flash"
api_key = "sk-你的key"
extra_body = { thinking = { type = "disabled" } }   # 关掉“思考”，否则又慢又可能返回空
```

- 只有你在输入框里打的那句话会发给这个服务；队友的语音、字幕都不会。
- 需要联网，按服务商的价格计费（一句话很短，花费极少）。每句大约 1 秒。
- 在线服务可能拒绝翻译某些句子（比如涉及政治的内容或很重的脏话）。遇到拒绝、断网或 key 失效时，这一句会**自动改用本地的字幕模型**翻译，输入框下方会提示。
- 包含 `local_only` 里词语的句子不会发给在线服务，直接由本地模型翻译。默认只有一个词（见 `config.example.toml`），哪些词让在线服务翻得不对，自己加进去即可：`local_only = ["词1", "词2"]`。
- `config.toml` 和 `valoroyce.state.json`（设置窗口把 key 存在这里）不会被提交到 git，但也别把带 key 的文件发给别人。

**本地的第二个模型**（仍然完全离线）：把一个 GGUF 格式的聊天模型（例如 Qwen3.5-4B 的 Q4_K_M 版，约 2.7 GB）放进 `models` 文件夹，然后：

```toml
[compose]
backend = "llama"
model_file = "Qwen3.5-4B-Q4_K_M.gguf"
```

它会在第一次打开输入框时才加载。语气比默认模型自然，但准确度不如在线的大模型，而且会多占内存或显存。

### 字幕用自己选的翻译模型（可选）

默认的字幕翻译模型 Hy-MT2 很小、很快、完全离线，但口语、梗和不完整的句子常常翻得生硬，有时干脆照抄原文。可以让字幕**先交给你自己选的模型**翻译，Hy-MT2 留在后面兜底：

- 在设置窗口的「模型」页勾选「自定义翻译模型」的**启用**，再到「翻译」页选类型、填地址和模型名。有 Ollama、LM Studio 和 DeepSeek 的一键填写按钮。
- **本机的模型服务**（Ollama、LM Studio 等，选「兼容 OpenAI 接口的服务」）或**自己的 .gguf 文件**（放进 `models` 文件夹，选「自己的 .gguf 模型文件」，程序会自己启动它）：仍然完全离线，但会和 Hy-MT2 各占一份显存。
- **在线服务**（例如 DeepSeek，需要自己的 API key）：翻得明显更地道。但要知道两点，设置窗口里也写着：
  - 队友说的**每一句话**（识别出的文字）都会发给这个服务，不再只在本机处理。默认是关闭的。
  - 有的在线服务会在某些话题上**悄悄改写句子**，意思可能和原话相反，字幕上看不出来。
- 它出错、断网、拒绝翻译，或者超过「超时」（默认 2.5 秒）还没译完的句子，**自动改用 Hy-MT2**；连续出错时会暂停使用它 30 秒，并在屏幕上提示一次。Hy-MT2 停用时，这些句子只替换术语。
- 说话过程中的半句字幕默认仍由 Hy-MT2 翻译（快，而且不产生费用），说完的整句才发给它，所以整句定稿会比只用 Hy-MT2 晚大约 1 秒。实测（一局比赛的录音，DeepSeek）：每句约 1 秒，整句字幕在说完后中位 2.1 秒出现（只用 Hy-MT2 时约 1 秒）。
- 手写配置见 `config.example.toml` 的 `[translate.custom]`；key 也可以放在环境变量 `VALOROYCE_CAPTION_API_KEY` 里。

### 显卡还是 CPU？

翻译模型默认放在显卡上跑，出字幕更快，但它会和游戏共用显卡（约占 1.5 GB 显存；用 Whisper 识别时再加约 1.2 GB）。如果开着字幕时游戏掉帧或卡顿，在托盘菜单或设置窗口的「翻译」页把翻译切到 **CPU** 即可；CPU 模式下短句定稿大约 1 秒。显存只有 4 GB 的显卡建议一开始就这样设置。

## 只翻译队友语音（强烈建议）

默认录的是电脑播放的**全部**声音，所以枪声、技能音效、英雄台词都会混进来，英雄台词也会被翻译。把语音聊天单独分到一个播放设备上，字幕就只跟队友的声音走：

1. 游戏内 设置 → 音频 → 语音聊天 → **输出设备**，选一个和游戏声音不同的设备。
   - 有些耳机自带「Game / Chat」两个设备，直接选 Chat 那个。
   - 只有一个设备的话，装一个虚拟声卡（如 VB-CABLE），把语音输出选成它，再在 Windows 声音设置里对这个虚拟设备勾选「侦听此设备」，转回你的耳机。
2. 在托盘菜单的「声音来源」或设置窗口的「声音与识别」页里选中这个设备。（也可以写进配置文件：`[audio] device = "CABLE"`，填设备名的一部分即可，`uv run valoroyce devices` 可以列出设备名。）

## 和朋友另外开语音通话时

如果你们在 QQ、KOOK、Discord 之类的软件里用中文聊天，默认这些声音也会被识别和翻译。在设置窗口的「声音与识别」页，把「听哪些程序」选成「除一个程序以外的全部程序」，再在「程序」里选中通话软件（先让它出声，再点「刷新」），字幕就不会理会你们的聊天。也可以反过来选「只听一个程序」。这和 OBS 的「应用程序音频捕获」用的是同一个 Windows 功能，不需要管理员权限，不会改变你听到的声音，也不碰游戏。需要 Windows 10（2004 版）或更新的系统。配置文件写法：`[audio] app = "KOOK.exe"`、`app_mode = "except"`。

据网上的反馈，VALORANT 的队伍语音由 Riot 客户端（`RiotClientServices.exe`）播放，而不是游戏本身。如果属实，「只听」它就只剩队友的声音，没有枪声和英雄台词，但这一点还没有在对局里验证过。

## 配置

常用的选项在设置窗口里都能改，不需要碰配置文件。想手写配置（或用到设置窗口里没有的选项）时，把 `config.example.toml` 复制为 `config.toml` 再改，所有项都可以不写。注意设置窗口里改过的项目优先于 `config.toml`。常用的几个：

| 想做的事 | 配置 |
|---|---|
| 语音识别模型的使用顺序 | `[asr] order = ["whisper", "sensevoice"]`（没写进来的不会用） |
| 只听日语（识别更稳） | `[asr] languages = ["ja"]` |
| 字幕出得更快 / 更完整 | `[vad] min_silence = 0.25`（更快）或 `0.5`（少把一句话切碎） |
| 字号、停留时间、位置 | `[overlay] font_size / linger / y` |
| 同时显示日语原文 | `[overlay] show_source = true` |
| 翻译不用显卡 | `[translate] gpu = false`（或托盘菜单切换） |
| 没有显卡，CPU 吃紧 | `[translate] partials = false`（只翻译说完的整句） |
| 发消息的默认语言、快捷键 | `[compose] target = "en"`、`hotkey = "ctrl+shift+f8"`、`voice_hotkey = "ctrl+shift+f9"`（留空则不注册快捷键） |
| 发消息用更强的模型（在线或本地） | `[compose] backend = "openai"` 或 `"llama"`，见上文「想翻得更地道」 |
| 字幕先用自己选的模型，Hy-MT2 兜底 | `[translate.custom] backend = "openai"`（或 `"llama"`），见上文「字幕用自己选的翻译模型」 |
| 字幕只用自己的模型服务（Ollama / LM Studio 等），不要 Hy-MT2 | `[translate] backend = "openai"`，并设置 `base_url`、`model`、`prompt = "generic"` |
| 不要翻译模型，只替换术语 | `[translate] backend = "none"` |

### 自己加术语

新建一个文件，例如 `my_terms.toml`：

```toml
terms = [
  { zh = "壹决", kind = "agent", en = ["Iso"], ja = ["アイソ"], mishear = ["愛想"] },
  { zh = "白给", kind = "callout", ja = ["無駄死に"] },
]
```

然后在 `config.toml` 里 `[glossary] extra = ["my_terms.toml"]`。`kind` 为 `agent / weapon / map` 的词一定会按你写的译名显示；`callout` 只是给翻译模型的参考。`mishear` 填识别器常写错的样子；`zh_alias` 填中文里的其他叫法（如 `zh_alias = ["保安"]`），发消息时会认出来。内置词表在 [`src/valoroyce/data/valorant.toml`](src/valoroyce/data/valorant.toml)，欢迎提 PR 补充。

## 延迟

在一台没有显卡的 16 核 Linux 机器上实测（翻译模型纯 CPU、4 线程）：

- 对方说话过程中，约每 0.5 秒刷新一次半句字幕，每次从收到声音到出字 0.2–1.3 秒；
- 说完之后的定稿字幕：短句约 0.8–1.0 秒，长句（5 秒、三十多个字）约 2 秒。其中 0.35 秒是用来判断「这句说完了」的静音等待。

把翻译线程数从 4 调到 8 后，短句定稿降到约 0.65–0.7 秒。翻译占了延迟的大头，用显卡跑预计会明显更快，但我们手头没有带显卡的机器，具体数字尚未实测。

## 常用命令

```sh
uv run valoroyce devices                      # 列出音频设备和正在发声的程序
uv run valoroyce run --file some.wav          # 用录音文件测试
uv run valoroyce run --no-overlay             # 不开悬浮窗，字幕打印在终端
uv run valoroyce run --cpu                    # 本次运行不使用显卡
uv run valoroyce run --record                 # 把听到的声音和字幕存到 recordings/，反馈问题用
uv run valoroyce translate "アイソがロングにいる"   # 直接测试术语和翻译
uv run valoroyce say --to en "保安在B点"        # 中文 → 日语 / 英语
uv run valoroyce quit                         # 关闭正在运行的 Valoroyce（连同它启动的翻译服务）
uv run --extra dev pytest                     # 跑测试
```

用安装程序装的版本没有 `uv run`：把上面的 `uv run valoroyce` 换成安装文件夹里的 `.venv\Scripts\valoroyce.exe`。

## 已知问题

- 英雄台词、技能语音会被当成人说话（见上面「只翻译队友语音」）。
- 几个人同时说话会混成一句，目前不区分说话人。
- 半句字幕会随着对方继续说而改写，偶尔会跳动。
- 字幕不做任何过滤：队友骂人、说脏话或聊敏感话题，都会照原意翻译出来（脏话的语气可能比原话略轻）。
- 游戏术语的识别主要靠事后纠正，生僻的说法还是可能识别错；遇到了请把「识别成了什么 / 实际是什么」提给我们，加进词表就能修好。

### 字幕不对时：录一段发给我们

识别错、翻译错、几句话粘在一起时，最有用的反馈是一段录音。在托盘菜单勾选「录音用于反馈问题」，让问题重现一会儿，再点一次停止（最长 10 分钟，到时自动停）。程序会在 `recordings` 文件夹里存两个同名文件并打开这个文件夹：

- `.wav`：程序听到的声音，和交给识别模型的一模一样
- `.txt`：当时显示过的每一条字幕（识别出的原文、译文、时间）

录音只保存在你的电脑上，不会上传。里面有别人的声音，要不要发给别人由你决定。命令行里也可以用 `uv run valoroyce run --record`。
